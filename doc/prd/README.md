# Physiotherapy Clinic Management Platform — PRD Set

Lean, Nigeria-scoped PRDs derived from the client proposal, ready to hand to your IDE/dev agent for build.

Single clinic, no multi-tenancy, minimal compliance overhead, mobile app via **Capacitor** (Android + iOS) wrapping the patient-facing web app.

## What's deliberately excluded (v1)

Insurance claims, payroll, telemedicine, advanced EHR integrations, exercise video library, biometric/ROM tracking, inventory management, advanced AI, multi-branch management, complex approval/audit UIs — matching the original proposal's excluded-features list.
