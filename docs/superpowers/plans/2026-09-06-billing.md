# Billing & Payments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Staff invoicing with fast manual payments, Paystack online payments behind a placeholder key, and portal balance/history/Pay Now.

**Architecture:** New `src/server/services/billing.ts` owns invoices, payments, balances, and revenue (money as Decimal strings end to end, status derived from payment sums); new `src/server/payments/paystack.ts` isolates Paystack HTTPS calls (native fetch, no SDK); webhook stays a REST route handler; portal reads through a new `getPortalBilling`.

**Tech Stack:** Next.js 16 App Router, React 19, Prisma 7, PostgreSQL 17, Tailwind v4, Paystack REST API, Vitest, Playwright.

## Global Constraints

- Prisma 7: import from `@/generated/prisma/client`, never `@prisma/client`. A `PrismaPg` driver adapter is mandatory.
- ESM only (`"type": "module"`). No `require()`.
- Timezone is `Africa/Lagos`, from `TIMEZONE` in `src/lib/constants.ts`. Never hardcode it.
- Enum values are `snake_case`. `PaymentMethod` is `cash | bank_transfer | pos | online_gateway` — the gateway method is `online_gateway`, not `online`.
- Exact dependency versions, no `^`/`~`. No new dependencies — Paystack uses native fetch, no SDK.
- Never run `npm install` casually. No install needed in this plan at all.
- Design tokens only; `font-display` for headings; tabular figures for money.
- Three auth layers: `requireRole`/`requirePageRole` at pages/actions; service-layer scoping (`canViewPatient`, role gates: invoice/payment writes are admin + receptionist only); portal ids from session, never URL.
- Money: Prisma Decimal accepted as decimal strings; kobo conversion by integer math only at the gateway edge.
- Secrets in `.env` (gitignored), placeholders only in `.env.example`. Never commit secrets, never log them.

```ts
import type { SessionUser } from "@/server/auth/session";
import { ForbiddenError } from "@/server/auth/rbac";
import { canViewPatient } from "./patient";

function assertCanBill(actor: SessionUser): void {
  if (actor.role !== "admin" && actor.role !== "receptionist") {
    throw new ForbiddenError("Billing is restricted to admin and reception staff");
  }
}

async function nextInvoiceNumber(tx: { invoice: { count: () => Promise<number> } }): Promise<string> {
  const count = await tx.invoice.count();
  return `INV-${String(count + 1).padStart(6, "0")}`;
}

export async function createInvoice(actor: SessionUser, input: InvoiceInput) {
  assertCanBill(actor);
  const parsed = invoiceSchema.parse(input);
  if (!(await canViewPatient(actor, parsed.patientId))) throw new Error("Patient not found");
  return prisma.$transaction(async (tx) => {
    for (let attempt = 0; attempt < 5; attempt++) {
      try {
        const total = parsed.items.reduce((sum, i) => sum + Number(i.quantity) * Number(i.unitPrice), 0);
        // Decimal-safe total: recompute in integer kobo, then back to string.
        const totalKobo = parsed.items.reduce((sum, i) => sum + Math.round(Number(i.quantity) * Math.round(Number(i.unitPrice) * 100)), 0);
        const totalStr = (totalKobo / 100).toFixed(2);
        const created = await tx.invoice.create({
          data: {
            invoiceNumber: await nextInvoiceNumber(tx),
            patientId: parsed.patientId,
            appointmentId: parsed.appointmentId ?? null,
            totalAmount: totalStr,
            notes: parsed.notes ?? null,
            createdById: actor.id,
            items: { create: parsed.items.map((i) => ({ description: i.description, quantity: i.quantity, unitPrice: i.unitPrice, amount: ((Math.round(Number(i.quantity) * Math.round(Number(i.unitPrice) * 100))) / 100).toFixed(2) })) },
          },
        });
        return created;
      } catch (e) {
        if (isUniqueViolation(e) && attempt < 4) continue; // invoice_number race: retry
        throw e;
      }
    }
    throw new Error("Could not number the invoice. Try again.");
  });
}
```

Read how the codebase detects Prisma P2002 (`error instanceof Prisma.PrismaClientKnownRequestError && error.code === "P2002"` in booking.ts) and use exactly that for `isUniqueViolation` — do not invent a helper with different semantics.

`recordManualPayment`: assertCanBill, parse (amount decimal-string > 0, method enum minus online_gateway — manual methods only; reject `online_gateway` with "recorded automatically"), load invoice + paid sum, reject amount > remainder ("exceeds the outstanding"), create payment with recordedById = actor.id, recompute status (remainder 0 → paid, paid > 0 → partially_paid) and update invoice. ```ts
// src/server/payments/paystack.ts
import "server-only";
import { createHmac, timingSafeEqual } from "node:crypto";
import { env } from "@/lib/env";

export function isGatewayConfigured(): boolean { return Boolean(env.PAYSTACK_SECRET_KEY); }
export function nairaToKobo(naira: string): number { return Math.round(Number(naira) * 100); }
export function verifyWebhookSignature(rawBody: string, signature: string, secret: string): boolean {
  const digest = createHmac("sha512", secret).update(rawBody).digest("hex");
  const a = Buffer.from(digest), b = Buffer.from(signature);
  return a.length === b.length && timingSafeEqual(a, b);
}
export async function initializePayment(input: { email: string; amountKobo: number; invoiceId: string; callbackUrl: string }) {
  if (!isGatewayConfigured()) throw new Error("Online payment is not configured");
  const res = await fetch("https://api.paystack.co/transaction/initialize", {
    method: "POST",
    headers: { Authorization: `Bearer ${env.PAYSTACK_SECRET_KEY}`, "Content-Type": "application/json" },
    body: JSON.stringify({ email: input.email, amount: input.amountKobo, callback_url: input.callbackUrl, metadata: { invoiceId: input.invoiceId } }),
  });
  if (!res.ok) throw new Error("Could not start the online payment. Try again.");
  const data = (await res.json()) as { status: boolean; data: { authorization_url: string; reference: string } };
  if (!data.status) throw new Error("Could not start the online payment. Try again.");
  return { authorizationUrl: data.data.authorization_url, reference: data.data.reference };
}
export async function verifyPayment(reference: string) { /* GET /transaction/verify/:reference → { paid, amountKobo } */ }
